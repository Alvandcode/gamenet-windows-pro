# 🎮 گیم‌نت منیجر پرو

سلام! من الوندم. این برنامه رو اول برای گیم‌نت خودمون نوشتم چون از دفتر و خودکار و حساب‌کتاب ذهنی خسته شده بودم. بعد دیدم بد نشده، تمیزش کردم و گذاشتم اینجا که بقیه هم استفاده کنن.

## این برنامه چی کار می‌کنه؟

خلاصه‌اش: مدیریت کامل یه گیم‌نت یا گیم‌سنتر. تایمر هر دستگاه، حساب کتاب مشتری، بوفه، رزرو، گزارش درآمد... همه‌چی یه‌جاست و بدون اینترنت هم کار می‌کنه (اطلاعات رو خود سیستم نگه می‌داره).

چیزایی که داره (کم‌کم اضافه شده، اگه چیزی کمه بگو):
- تایمر هر سیستم با هشدار تموم شدن (صدا + چشمک)
- حساب کردن مبلغ از روی ساعت، یا برعکس: پول رو بزنی خودش میگه چند دقیقه میشه
- تعرفه جدا برای هر نوع دستگاه (کامپیوتر، پلی‌استیشن، ایکس‌باکس، بیلیارد، فوتبال‌دستی...)
- تعرفه ساعتی (مثلا شب‌ها گرون‌تر)
- رزرو دستگاه برای مشتری با هشدار تداخل
- بوفه: موجودی، قیمت خرید/فروش، سود
- کیف پول مشتری، بدهی، شارژ
- رتبه‌بندی مشتری‌ها و تخفیف + تخفیف تولد 🎂
- فاکتور PDF و فرستادن با تلگرام/واتساپ/روبیکا/ایمیل
- نمودار درآمد روزانه/هفتگی/ماهانه/سالانه و مقایسه دو ماه
- بکاپ خودکار روزانه
- ورود با اپراتور (محدود کردن دسترسی شاگرد!)
- ۲۱ تا تم رنگی 😄
- کنترل کامپیوتر مشتری از راه دور (با ایجنت جدا، تو شبکه داخلی): قفل خودکار، هشدار رو مانیتورش، خاموش کردن

## دو تا نسخه داریم

1. **اندروید (رایگان):** امکانات پایه — تایمر، رزرو، PDF. برای تست و مغازه‌های کوچیک خوبه.
2. **ویندوز پرو (پولی):** همه امکانات بالا. قیمت لایسنس ۳ کاربره یک میلیونه، هر کاربر اضافه ۲۰۰ هزار تومن. از [صفحه خرید](https://alvandcode.github.io/gamenet/) می‌تونی بگیری.

## نصب (راحت‌ترین راه)

برو تو بخش [Releases](../../releases) همین ریپو، آخرین نسخه رو دانلود کن:
- `Gamenet Manager Pro Setup.exe` → نصب می‌کنی مثل بقیه برنامه‌ها
- نسخه Portable هم هست، بدون نصب اجرا میشه

## اگه دولوپری و می‌خوای بیلد بگیری

Node 20 به بالا لازم داری:

```bash
npm ci
npm test
npm start
npm run dist:win
```

ساختار کد: `main.js` (بخش اصلی)، `preload.js` (پل امن)، `index.html` (پوسته سبک)، بقیه منطق تو `src/js/` و استایل تو `src/styles/`. تست‌ها تو `tests/` هستن، قبل هر کاری `npm test` رو بزن.

نکته: کلید فایربیس و ابزار ساخت لایسنس تو ریپو نیست (امنیت!). اگه فروشنده‌ای و دسترسی داری که خودت می‌دونی کجان 🙂
